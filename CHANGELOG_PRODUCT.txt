3.2.1 Remote Mobile / SonoBus Low-Latency

- Added persisted Final Output target: Local / SonoBus→Smartphone Headphones-IEM / SonoBus→Smartphone Speaker.
- SonoBus mobile headphone target automatically enables the existing dataset-free parametric HRTF path; no external HRTF dataset or cloud lookup is required.
- Remote smartphone speaker target explicitly disables binaural HRTF behavior.
- Remote targets request AudioContext latencyHint=interactive and 48 kHz with safe fallback; Diagnostics expose browser base/output latency separately from DSP cue delays.
- Added conservative remote-mobile Spatial profiles with low reflections and bounded sub-ms spatial cues.
- Remote route selection is explicit/persisted because Web Audio cannot identify a remote SonoBus peer or the phone's final headphone/speaker path.
- Added remote-mobile regression test.

3.2.0 3D Spatial Ecosystem
- 既存DSPの後段、Auto Level / Adaptive Safety / Limiterの前へ独立3D Spatial Layerを追加。
- Spatial OFF時はDry本線を維持し、Wet枝をフェード後に切断してCPU負荷を抑制。既存プリセット変更でもSpatial状態を保持。
- Headphone/IEMとSpeakerで別の保守的アルゴリズムを使用し、既存HRTF有効時は二重HRTFを回避。
- Device Profile Registry、出力デバイス選択/変更検出、default fallback、Chrome storage永続化を追加。
- AUTO / NATURAL / WIDE / DEEP、詳細Spatial Diagnostics、GIRO向けspatial:*イベントを追加。
- Neutral(内部preset名 flat) / Self-DAPを含む旧設定・プリセット回帰、mock Web Audio、静的統合、参照モデル検証を追加。
- 実機Chrome/Web AudioのI/O測定値は捏造せず、手動確認手順をSPATIAL_IMPLEMENTATION_REPORT.txtへ記載。
